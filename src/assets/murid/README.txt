Stok foto/GIF kejutan ujian lisan.

Bikin satu folder per anak, namanya = nama murid huruf kecil, spasi jadi "-".
Contoh:
  src/assets/murid/ahmad-fauzi/lucu.gif
  src/assets/murid/ahmad-fauzi/foto1.jpg
  src/assets/murid/siti-aminah/kucing.gif

Guru cuma melihat foto milik anak yang sedang diuji.
Daftar file dibaca saat BUILD, jadi setelah menambah foto perlu deploy ulang.
